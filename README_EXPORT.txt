Y M S AI — Source Code Export

This archive contains the project source, shared libraries, app/server configuration, and package lockfiles.
Dependencies, generated build output, local Replit agent data, and uploaded reference assets are excluded. No .env files or credentials are included.

Setup (from the project root):
1. Install pnpm (the project requires pnpm).
2. Run: pnpm install
3. Configure the required environment variables/secrets for Clerk and the OpenAI integration.
4. Start the app using the project's Replit workflows or its package scripts.

The repository is a pnpm monorepo. See package.json and pnpm-workspace.yaml for workspace commands.
